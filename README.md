# 🌀 YiTarot-AI：周易 × 塔罗 × AI 智能占卜系统

> **融合东方《周易》六爻与西方塔罗牌，借助大语言模型（LLM）生成个性化、有温度的双轨占卜解读。**

本项目从一个简单的铜钱模拟程序出发，逐步迭代为具备可视化交互、多文化符号融合与 AI 深度解析能力的智能占卜系统，探索传统文化在数字时代的表达可能。

---

## 📂 项目结构与版本演进

### 🔹 版本一：`铜钱算卦程序（多屏幕.py）` —— 基础逻辑验证
- **目标**：准确模拟传统“三枚铜钱起卦”流程。
- **技术**：Python 内置 `turtle` 模块，双画布设计（左：掷币动画；右：卦象绘制）。
- **功能**：
  - 随机生成六爻（含老阳/老阴动爻标识）
  - 自动查表输出本卦名称与《周易》卦辞
- **意义**：验证核心算法可行性，还原手工起卦体验。

### 🔹 版本二：`app.py` —— PyQt6 可视化交互系统
- **目标**：打造沉浸式、响应式的桌面占卜应用。
- **技术栈**：
  - GUI 框架：`PyQt6`
  - 动画：自定义硬币翻转、弹性卦象（Jelly Effect）、粒子星空背景
  - 数据结构：六爻状态管理、塔罗牌阵（过去-现在-未来）
- **功能亮点**：
  - 六次点击完成周易起卦，动爻高亮
  - 独立塔罗抽牌流程，支持正逆位翻转
  - 并列展示周易结果与塔罗牌面，形成双体系对照

### 🔹 版本三：AI 智能解读集成（`app.py` 中的 `AIThread`）
- **目标**：突破静态文本局限，提供情境化、心理关怀型解读。
- **技术集成**：
  - 大模型 API：兼容通义千问（DashScope）、OpenAI 等
  - Prompt 工程：结构化输入（用户问题 + 卦象 + 塔罗牌）
  - 异步通信：`QThread` + `requests` 避免界面卡顿
- **输出特点**：
  - 自然语言段落，非列表式机械回复
  - 关键词加粗，语气神秘而温暖
  - 支持后续追问，形成“占卜—反思”对话闭环

## ⚙️ 技术依赖

```txt
Python >= 3.8
PyQt6
requests
turtle (仅版本一)
```

> 注：AI 功能需配置大模型 API 密钥（如 DashScope 的 `DASHSCOPE_API_KEY`），默认关闭。

## ▶️ 快速启动

1. 克隆仓库：
   ```bash
   git clone https://github.com/yourname/YiTarot-AI.git
   cd YiTarot-AI
   ```

2. 安装依赖：
   ```bash
   pip install PyQt6 requests
   ```

3. 运行主程序：
   ```bash
   python app.py
   ```

4. （可选）启用 AI 解读：
   - 在代码中填入你的 API Key
   - 确保网络可访问对应大模型服务
